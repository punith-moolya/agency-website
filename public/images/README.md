# /public/images

Drop real photography here, then point to it from `lib/images.ts`
(that's the only file that needs editing — see the big comment at the
top of that file for the full walkthrough).

Suggested folders (already created, empty for now):

- `hero/` — background texture / brand photography for the dark hero card
- `about/` — studio, team, or workspace photography for the About section
- `team/` — individual headshots, one per person (square or 4:5 works best)
- `portfolio/` — project thumbnails for the Featured Projects grid (4:5 works best)

Recommended sizes:

- Team headshots: at least 800×1000px
- Portfolio thumbnails: at least 1200×1500px
- Hero / about photography: at least 1600×2000px

Any format Next/Image supports works (`.jpg`, `.png`, `.webp`, `.avif`).
